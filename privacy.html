Datenschutzerklärung – Jarvis Calendar

Stand: 15. November 2026

Wer die Anwendung nutzt

Jarvis Calendar ist eine private Anwendung, die ausschließlich ihr Betreiber mit seinem eigenen Google-Konto nutzt. Andere Personen werden nicht angesprochen und können sich nicht anmelden.

Welche Daten verarbeitet werden

Mit Zustimmung des Betreibers greift die Anwendung über die Google Calendar API auf dessen eigene Kalender zu: Termine lesen (Titel, Zeit, Ort, Beschreibung) und neue Termine anlegen.

Wo die Daten verarbeitet werden

Die Daten werden ausschließlich im privaten Heimnetz des Betreibers verarbeitet, in seinem selbst betriebenen Home Assistant und einem lokal laufenden Sprachmodell. Es findet keine Weitergabe an Dritte, keine Analyse zu Werbezwecken und kein Verkauf von Daten statt. Die Zugangsdaten (OAuth-Token) liegen nur in diesem Home Assistant.

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Danach kann die Anwendung nicht mehr auf den Kalender zugreifen.

Google API Services User Data Policy

Die Nutzung von Daten, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

English summary

Private app used only by its owner with their own Google account. Calendar data is read and events are created solely within the owner's self-hosted Home Assistant on their home network. No data is shared, sold or used for advertising. Access can be revoked at any time via myaccount.google.com/permissions.
